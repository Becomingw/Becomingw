# Profile visuals

`header.svg` is an original vector banner. `stats-*.svg` and `languages-*.svg` are generated by `scripts/update-profile.py`, with light and dark variants selected by the profile README.

The workflow refreshes the cards daily and can also be run manually from **Actions → Refresh profile cards → Run workflow**. It uses GitHub's built-in token; no personal access token or external statistics server is required for these four cards. Failed API requests leave the existing assets intact.

Metrics use only public, owned, non-fork repositories. Stars and forks are sums across those repositories. Languages count each repository's primary language; they are not byte shares or proficiency scores. Archived original repositories are included. Followers come from the public user profile. Each card displays its snapshot date.

Shields.io supplies the badges, Skill Icons supplies the technology icons, and GitHub Readme Streak Stats supplies the contribution streak card. Those external images may be cached or temporarily unavailable; the biography, project links, banner, and snapshot cards remain readable independently.

The profile intentionally uses GitHub-supported Markdown, HTML tables, `picture` elements, and SVG images. It does not depend on scripts or custom CSS in the README.
